# 其他功能集群

本目錄保存不屬於 NLP 或金流，但可作為獨立功能集合的通用能力。每個子集群都維持自己的語言邊界與 README。

## 責任

- 分類可靠性、訊息 transport、身份解析、事件時間線、互動規則、地理解析與遊戲規則能力。
- 防止將派單、健康、會員、租戶、Android 或 Unity 專案語意混入通用模組。
- 讓每一功能集群有明確責任、公開契約、來源追溯與禁止用途。

## 語言子目錄

- `python/`：可靠性、訊息、事件與互動規則。
- `kotlin/`：離線地址與座標值物件。
- `csharp/`：純規則卡牌核心與偽裝狀態機。

- 不得將來源專案的租戶設定、健康資料、派單規則、Android／Unity UI、資產或建置內容帶入本目錄。
- 不得修改、搬移、新增或刪除任何來源專案檔案。
- 不得將遊戲內的資源或狀態誤當作商業付款或身分授權。
